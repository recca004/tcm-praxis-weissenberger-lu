# Phase 8 — Cleanup Audit

Baseline recorded on branch `feature/astro-source-cleanup`, forked from `feature/astro-static-migration` @ `7f02528`.

## Baseline

- `npm run build`: **29 pages** built in ~1.2 s (27 localized pages + root redirect + 404)
- `dist/` output: 39 files, **3.5 MB**
- `dist/_astro/` JS bundle: **571 KB** — a single bundle containing GSAP + ScrollTrigger + **the entire `lucide` icon catalogue** (~1500 icons) because `BaseLayout.astro` imports `import { createIcons, icons } from 'lucide'`.
- CSS: 5 files in `public/assets/css/` served unbundled (variables 2.7 KB, base 3.4 KB, layout 11.3 KB, components 19.0 KB, responsive 4.5 KB = 40.9 KB raw).
- Images in `public/assets/images/`: hero-clinic.jpg 724 KB, tcm-cupping.jpg 696 KB, tcm-herbs.jpg 904 KB (~2.3 MB total, unoptimized).
- Preview verified: `/`, `/de/`, `/en/`, `/zh/`, inner pages and `404.html` all return 200.

### Content issues found during audit

| Issue | Detail |
|---|---|
| **Duplicate CTA banner on home** | `src/content/*/home.html` ends with a `.cta-banner` section **and** `[...slug].astro` renders `<CTASection>` after the content → the closing CTA renders twice on every home page. |
| **Runtime icon injection** | 100+ `<i data-lucide>` placeholders in content fragments require the whole `lucide` package (571 KB bundle). Moving icons to `@lucide/astro` removes it. |
| **Duplicated markup** | Booking widget ×2 per locale (home + booking page), CTA banner ×5 per locale, treatment cards ×2 per locale, practitioner block ×2, back-link ×8, contact details/form ×2, price table ×2. |
| **CSS not bundled** | `public/assets/css/*.css` served as 5 separate requests, not minified/hashed. Move to `src/styles/` and import. |
| **Booking button icon bug** | `booking-demo.js` sets `nextBtn.textContent`, wiping the chevron icon; `initLucideIcons()` re-scan cannot restore it. Fix via label span. |
| **FAQ count differs per locale** | de has 6 FAQ items, en/zh have 5 — intentional per-locale content, preserve as data. |
| **`data-lucide` in Astro components** | Hero, TrustStrip, CTASection still use runtime placeholders → convert to `@lucide/astro`. |
| **Two lockfiles** | `bun.lock` + `package-lock.json` → keep npm only. |
| **`.playwright-mcp/` snapshots** | Test artifacts; gitignore. |
| **`.impeccable/shots/*.jpeg`** | Working screenshots committed inside tool state dir; keep dir but ignore `shots/`. |
